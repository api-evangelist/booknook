# BookNook

> BookNook is a K-8 high-impact tutoring company that delivers live 1:1 and small-group virtual
> instruction in reading and math through its own online learning platform. Schools and districts
> license the platform and either use BookNook's tutor corps or run sessions with their own staff.
> **BookNook publishes no public API, no developer portal, and no machine-readable contract.**

## What an agent should know first

- There is **no public BookNook API**. Do not attempt to construct calls against
  `api.booknooklearning.com` — it is the platform's own backend, undocumented, and not offered
  to third parties. Its root returns `{"success":true,"message":"BookNook API: <timestamp>","data":{}}`
  and it is listed as an "API" component on the public status page, but no reference, no
  OpenAPI, no GraphQL SDL and no MCP server exists.
- There is **no OpenAPI, AsyncAPI, GraphQL SDL, Postman collection, JSON Schema, SDK, CLI or
  agent card** anywhere on BookNook's public surface (probed 2026-08-08).
- Access to the product is through district/school licensing, not self-serve signup. The public
  entry point is a demo request, not an API key.
- Integration with BookNook happens **through partner platforms**, not through a BookNook API:
  Clever Instant Login (SSO), Clever Secure Sync (rostering and account provisioning), and
  ClassLink SSO. BookNook is the consumer of those APIs.
